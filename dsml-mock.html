A · 简答（开放性）题

NN PPT + 数据中心补充考点 · 一句完整英文 · 10 × 2 = 20 分

1What is an artificial neural network?2 分
什么是人工神经网络？
An ANN is a system of neurons joined by weighted connections, where each neuron sums its weighted inputs and applies an activation function, so the knowledge lives in the weights.
✎ 评分要点：给分点：neurons + weighted connections / multiply-sum-activate / knowledge lives in the weights
人工神经网络是由带权连接的神经元组成的系统：每个神经元对加权输入求和并过激活函数，知识就存在权重里。
2Why does every neuron need a bias unit?2 分
为什么每个神经元都需要偏置单元？
The bias is a constant input 1 with its own weight that shifts the decision boundary away from the origin, because without it the boundary must pass through (0, 0).
✎ 评分要点：给分点：constant input 1 with own weight / shifts boundary off origin / like intercept in a line
偏置是恒为 1 的输入，把决策边界从原点移开，因为没有它边界被迫过 (0,0)。
3Name the four common activation functions and give the output range of each. Why are non-linear activations needed?2 分
写出四种常见激活函数及各自的输出范围。为什么需要非线性激活？
The four activations are sign (−1 or +1), sigmoid (0 to 1), tanh (−1 to +1) and ReLU (0 or positive), because without non-linearity even many layers act like one linear model.
✎ 评分要点：给分点：四个函数+范围各0.5 / 非线性原因1分
四种激活函数：sign（−1/+1）、sigmoid（0~1）、tanh（−1~+1）、ReLU（0或正数）；没有非线性，再多层也等价于线性模型。
4What is backpropagation and how does the chain rule make it work?2 分
什么是反向传播？链式法则如何实现它？
Backpropagation works backwards from the loss layer by layer, using the chain rule to give every weight its own gradient ∂L/∂w for gradient descent.
✎ 评分要点：给分点：starts from loss at output / moves backward layer by layer / chain rule multiplies local gradients
反向传播从损失端逐层向后，用链式法则给每个权重算出梯度，供梯度下降更新。
5What is the main goal of environmental monitoring?2 分
环境监测的主要目标是什么？
To track conditions like temperature and humidity so operators can prevent IT hardware overheating and premature equipment failure.
✎ 评分要点：给分点：track temperature / humidity 1 + prevent overheating / premature failure 1（CDC 真题 Q8 原题）
跟踪温度、湿度等环境条件，使运维人员能防止 IT 设备过热和过早损坏。（CDC 期中真题 Q8 命中）
6Describe one technique data centres use to achieve low-latency operations.2 分
描述数据中心实现低时延运营的一种技术。
Deploying edge data centres close to end-users, because it shortens the physical network distance that data packets must travel during request-response cycles.
✎ 评分要点：给分点：edge data centres close to end-users 1 + shortens physical distance 1（CDC 真题 Q13 原题）
把边缘数据中心部署在最终用户附近，因为缩短了请求-响应周期中数据包的物理传输距离。（CDC 期中真题 Q13 命中）
7Compare Mean Time Between Failures (MTBF) and Mean Time To Repair (MTTR).2 分
对比 MTBF 与 MTTR。
MTBF measures the average expected time a device runs before it fails, while MTTR measures the average time required to fix and restore a failed piece of equipment back to working order.
✎ 评分要点：给分点：MTBF=故障前平均运行时间 1 + MTTR=修复恢复平均时间 1（CDC 真题 Q10 原题；若考 MTTF：不可修复设备平均失效时间）
MTBF=设备平均运行多久才发生故障（越大越好）；MTTR=把故障设备修复恢复平均所需的时间（越小越好）。（CDC 期中真题 Q10 命中）
8What is a hyperscale data centre and what kind of workload is it built for?2 分
什么是超大规模数据中心？它为哪类负载而建？
A hyperscale data centre is an extremely large facility operated by major cloud providers that is purpose-built to handle massive-scale cloud computing, big-data and high-volume online service workloads.
✎ 评分要点：给分点：extremely large facility / major cloud providers 1 + cloud computing / big-data / online service workloads 1（CDC 真题 Q19 原题）
超大规模数据中心是由大型云服务商运营的巨型设施，专为大规模云计算、大数据与高流量在线服务负载而建。（CDC 期中真题 Q19 命中）
9What is overfitting and how do you fight it in neural networks?2 分
什么是过拟合？神经网络中如何对抗它？
Overfitting means the model memorises training data while validation loss rises, which we fight with early stopping, L2 and dropout.
过拟合=记住训练集、验证损失回升；对策是早停、L2 正则和 Dropout。
10How do you choose the number of clusters k in k-means?2 分
k-means 中如何选择簇数 k？
We choose k with the elbow method on WCSS or the highest silhouette score, because more clusters always lower SSE.
用 WCSS 肘部法或最高轮廓系数选 k，因为簇数越多 SSE 一定越小。

15Lab 3 style (8 marks). Load a toy classification dataset, CREATE an MLPClassifier, TRAIN it, and PREDICT on the test set with accuracy.8 分
代码题（Lab 3 同款）：加载玩具分类数据集，创建（create）MLPClassifier 模型，训练（train）它，并在测试集上预测（predict）给出准确度。
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPClassifier
from sklearn.metrics import accuracy_score

X_train, X_test, y_train, y_test = train_test_split(*load_digits(return_X_y=True), test_size=0.25, random_state=42)
model = MLPClassifier(hidden_layer_sizes=(32, 16), max_iter=500, random_state=42).fit(X_train, y_train)
print("Accuracy:", accuracy_score(y_test, model.predict(X_test)))
